# wait-what

Start from the concrete consequence, then explain the mechanism. Use terms from `/CONTEXT.md` where they reduce ambiguity, but do not pile on jargon.

If the previous explanation mixed claim, evidence, state, authority, or verification, separate those explicitly. Use one worked example when it clarifies the distinction.

Do not merely shorten the previous answer; change the explanatory model.
