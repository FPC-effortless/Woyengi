# wayfinder

Do not implement. Build a map of the decisions and evidence required to make implementation specifiable.

For each decision node record:
- question;
- current assumptions;
- primary evidence needed;
- plausible alternatives;
- constitutional/work-mode impact;
- reversibility and cost of being wrong;
- dependency on other decisions;
- owner/authority if not delegated.

For RL/research initiatives, include capability/hypothesis, dataset/ground-truth constraints, verifier choice, compute feasibility, and benchmark/baseline selection.

Collapse the map through research and grilling until one coherent route is ready for `to-spec`.
