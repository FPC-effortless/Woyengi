# ponytail-help
`ponytail lite` = requested shape + simpler option; `ponytail`/`ponytail full` = ladder enforced, default; `ponytail ultra` = deletion/YAGNI-first with all explicit/safety/state constraints preserved. Deactivate extra minimality with `stop ponytail`, `ponytail off`, or `normal mode`.

Skills: `ponytail`, `ponytail-review`, `ponytail-audit`, `ponytail-debt`, `ponytail-gain`, `ponytail-help`.

The Woyengi fusion is tool/mode independent and does not require upstream plugin installation. For upstream compatibility only, Ponytail documents `PONYTAIL_DEFAULT_MODE` and `~/.config/ponytail/config.json` (Windows `%APPDATA%\ponytail\config.json`) with env > config > full, plus host-specific slash/@ and plugin-update flows. Those host mechanics never override Woyengi authority.
