# FPC Universal Skill

One portable, evidence-driven coding/research skill with an on-demand capability index drawn from the accessible GitHub repository skills. Install once per machine/user account; keep project-specific instructions and skills where they belong.

**Entry:** `SKILL.md` · **Provenance/routing:** `references/skill-map.md` · **Global installation:** `references/install-and-precedence.md`.

From a trusted checkout of Woyengi:

- PowerShell: `powershell -ExecutionPolicy Bypass -File .agents/skills/fpc-universal/scripts/install.ps1`
- bash: `bash .agents/skills/fpc-universal/scripts/install.sh`

The installer is opt-in, scoped to the current user's home directory, and does not alter repository code or credentials. No installed skill can replace a platform's permissions or override project instructions.
