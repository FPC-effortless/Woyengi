# research

Start with a concrete research question and what decision it could change.

Source order:
1. repository code and canonical project docs for project facts;
2. official/first-party documentation;
3. original papers, standards, datasets, or source repositories;
4. direct reproducible experiments.

Prefer primary evidence over summaries. Distinguish observed facts, inferences, assumptions, and open questions.

Save durable research that affects future work under `docs/research/<YYYY-MM-DD>-<slug>.md` with:
- question;
- decision relevance;
- sources;
- findings;
- contradictions/uncertainty;
- recommendation and countercase;
- next falsifier/experiment.

For fast-changing external facts, verify recency rather than relying on memory.
